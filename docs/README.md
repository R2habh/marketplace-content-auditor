# Dashboard Screenshots

Place your dashboard screenshots here:

1. **dashboard-overview.png** - Main dashboard with KPIs, score distribution, top violations
2. **dashboard-violations.png** - Violations analysis tab with severity breakdown, field analysis
3. **dashboard-details.png** - Product detail view with violation recommendations

To capture:
1. Run `streamlit run dashboard.py`
2. Open http://localhost:8501
3. Press `Win + Shift + S` (Windows) or `Cmd + Shift + 4` (Mac)
4. Save as the respective files above

Recommended size: 1200x800px each
